# CCL/PPG 한국 독점 에이전시 조사 (2026-11-17)

> 출처는 대부분 2차 자료(뉴스·집계 사이트)라서 수치는 **미검증**입니다. 관세청 수입통계와 Prismark 원자료로 확인이 필요합니다.

## 1. 시장 상황: 에이전시에 유리한 타이밍

- 한국 CCL 수입 단가가 2026년 3월 톤당 20,728달러로 전년 대비 **74.5% 상승**했다고 보도됨 (AI 서버 수요로 공급 부족).
- 중국 Kingboard가 2026년 들어 FR-4 CCL·프리프레그 가격을 4번 인상 (4/28 기준 추가 10%). 대만 TUC, ITEQ, EMC도 여러 차례 인상.
- 두산은 국내 공장 가동률이 100%를 넘었고(증평 109.8%, 김천 102.7%), 국내 4,200억 원 + 중국 5,500억 원 증설을 2028년부터 단계 가동 예정.
- 글로벌 CCL 시장: 2025년 약 160억 달러 → 2026년 215억 달러 이상 전망(TPCA/ITRI 인용).
- 해석: 공급이 타이트해서 한국 PCB 업체들이 **대체 공급처**를 찾을 동기가 큼. 단, 중국 메이커도 공급이 빠듯해 한국에 물량을 배정할 여력이 있는지가 관건.

## 2. 경쟁 구도

- 글로벌 상위권: Kingboard, Shengyi(생익), EMC(台光電), TUC(台燿), Nan Ya Plastics(난야), ITEQ 등. 1위는 출처마다 달라 확정 불가.
- 한국 시장에는 두산(국내 제조)과 대만·중국 업체 직·간접 공급이 공존. **중국산 수입 점유율은 확인 못 함** (HS 코드 기반 관세청 통계 필요).

## 3. HRX 확인 결과

- "HRX"라는 CCL/PPG 제조사는 웹 검색으로 **확인되지 않음**. 정식 영문 법인명, 중국어 상호, 사업자등록번호(統一社會信用代碼)가 필요.
- 검증 방법: 중국 기업정보(企查查/天眼查), 공장 현장 방문 또는 영상 실사, 주요 고객·인증(UL, IATF 등), 생산 능력과 월 출하량 확인.

## 4. 리스크 (현금 흐름이 급한 상황에서 특히 중요)

1. **위임 구조의 위험**: 중국 측 지인에게 "독점 에이전시 미팅 진행"을 위임한 상태. 본인이 계약 당사자가 되지 않으면 **바이패스(직거래)**당할 수 있음. 독점 계약서에 본인 법인을 당사자로 명시하고, 고객 소개 시 비밀유지·비회피 조항을 넣을 것.
2. **독점의 실질성**: 독점 범위(한국 전체 vs 특정 품목), 최소 구매 목표, 기간, 해지 조건, 수수료율을 서면으로 확정.
3. **현금 흐름 구조**: 재고를 사서 파는 유통(자금 필요)보다, **수수료 기반 에이전시**(주문 시 메이커가 커미션 지급)가 지금 상황에 맞음. 커미션 지급 시점(선적 시/입금 시)과 환율·정산 방식 명시.
4. **인증 지연**: 한국 PCB 업체의 신규 자재 승인(qualification)은 보통 수개월 걸림 (경험적 추정, 업체별 확인 필요). 첫 매출까지 시간이 걸릴 수 있음.
5. **지재권·관세·무역 규제**: 한국 수입 관세, 중국산 규제 동향, 고객사(삼성·하이닉스 밸류체인) 공급망 정책 확인.

## 5. 현금 흐름을 앞당기는 제안

1. 독점 대기 중에도 매출이 나올 수 있도록 **스팟성 거래**(재고·잉여 물량, 소량 샘플) 가능 여부를 HRX에 타진.
2. 한국 PCB 업체 **타깃 리스트 20~30곳**을 만들어 샘플 승인을 병행 진행 (AI로 리스트·접촉 문안 작성 가능).
3. 난야 에이전시 시절의 **기존 고객 네트워크**가 가장 빠른 첫 매출 경로. 그 고객들이 지금 어디서 조달하는지부터 파악.
4. 부수입 경로로 반도체 원자재 단기 중개·컨설팅 가능 여부 검토.

## 6. 다음에 확인할 것

- HRX 정식 명칭과 제품 라인(FR-4, 고Tg, 할로겐프리 등), 월 생산 능력
- 위임받은 중국 측 인맥의 역할과 권한 범위, 계약 당사자 구조
- 난야 시절 고객 중 현재 연락 가능한 한국 업체 수
- 관세청 HS 코드 기준 CCL(7410/3921.90 등 해당 코드) 수입 통계
