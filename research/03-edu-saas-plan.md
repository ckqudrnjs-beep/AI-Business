# AI 교육·인사이트 구독 서비스 기획 + 수익 점검 (2026-11-17)

> 모든 수치는 **가정**입니다. `simulation/revenue_sim.py`의 입력값이며, 출시 후 실측치로 교체해야 의미가 있습니다. 법규 항목은 **확인 필요** 표시이며 법률 자문이 아닙니다.

## 1. 한 줄 정의 (초안, 분야는 확정 필요)

"직장인을 위한 AI 업무 자동화 마이크로러닝": 월 9,900~14,900원, 하루 10분, 주제별 실습 + 월간 인사이트 리포트.
분야는 `automation/config.json`의 `niche` 한 줄로 바꿀 수 있습니다. **본인이 직접 설명·검수할 수 있는 분야**여야 합니다(아래 리스크 1).

## 2. 수익 모델 점검

| 모델 | 장점 | 약점 | 판단 |
|---|---|---|---|
| 월 구독(9,900~14,900원) | 반복 매출, 계산 쉬움 | 해지율(월 5~12%)이 곧 성패 | **주력** |
| 단건 강의/전자책(2~5만원) | 초기 현금화 빠름 | 매달 새로 팔아야 함 | 구독 진입용 보조 |
| 기업 단체 구독(B2B) | 객단가·유지율 높음 | 영업 필요, 자동화 어려움 | 6개월 후 검토 |
| 광고/제휴 | 추가 수익 | 트래픽 대량 필요 | 부가 수익 |

**단위 경제성 (기준 시나리오)**: 판매가 14,900원 → 부가세 제외 13,545원, PG 수수료 3.3% 제외, LLM 원가 약 1,800원이면 유료 1인당 월 공헌이익 약 **11,300원**. 해지율 8%면 평균 유지 12.5개월, LTV 약 **14만원**.
광고로 고객 1명을 25,000원에 얻는다면 LTV/CAC ≈ 5.6배지만, **CAC 25,000원은 검증되지 않은 낙관 가정**입니다. 저가 교육 상품에서 CAC가 5만원을 넘으면 광고는 손해입니다. → 초기에는 광고 없이 콘텐츠 유입(SEO·뉴스레터·숏폼)만 쓰는 것을 권장합니다.

## 3. 시뮬레이션 결과 (24개월, 몬테카를로 5,000회)

가정: 유입·전환은 삼각분포, **시장 반응 실패 확률 35%** 반영, 광고비가 늘면 CAC 상승 반영.

| 지표 | 비관 10% | 중앙값 | 낙관 90% |
|---|---|---|---|
| 24개월차 유료 구독자 | 89명 | 197명 | 415명 |
| 24개월차 월매출 | 116만 | 264만 | 572만 |
| 24개월차 월 영업이익 | 33만 | 138만 | 379만 |
| 누적 손익 | +39만 | +1,184만 | +3,370만 |

- 24개월 누적 흑자 확률 91%, 필요 운영자금 중앙값 약 145만원, 보수적으로 **약 300만원**.
- 고정 시나리오: 비관(유료 2명, 월 -24만원, 누적 -590만원) / 기준(5개월차 흑자, 24개월 월이익 185만원) / 낙관(24개월 월이익 7,100만원).

### 이 숫자를 믿으면 안 되는 이유 (정직한 한계)
1. **인건비 0원 가정**. 본인 시간은 비용에 넣지 않았습니다. 월 이익 138만원이면 주 20시간 투입 시 시급 약 1.7만원 수준입니다.
2. **유입 가정이 지배적**. 민감도 1위가 첫 달 방문자(+0.51), 다음이 전환율입니다. 즉 "콘텐츠가 실제로 검색·SNS에서 노출되는가"가 사업의 성패이며 이건 시뮬레이션이 아니라 **4~8주 실험으로만 알 수 있습니다.**
3. 현금 기준이며 법인세·소득세·종합소득 미반영.
4. 무료 AI 도구와 유튜브 무료 강의가 경쟁자입니다. 차별점(한국 직장 맥락, 실습 템플릿, 최신 업데이트, 검수된 정확성)이 없으면 전환율이 비관값으로 갑니다.

## 4. 검증 계획 (돈 쓰기 전에)

| 주차 | 할 일 | 통과 기준 (미달 시 분야·메시지 변경) |
|---|---|---|
| 1~2 | 랜딩 페이지 + 대기자 명단, 콘텐츠 주 10편 발행 | 방문 500명 이상 |
| 3~4 | 대기자 대상 선결제(얼리버드 4,900원/월) 제안 | 방문→가입 3% 이상, 선결제 10명 |
| 5~8 | 유료 10명으로 콘텐츠 품질·해지 사유 점검 | 첫 달 유지율 80% 이상 |
| 9~ | 위 3개 통과 시에만 광고비 집행 검토 | CAC < 공헌이익 × 3 |

## 5. 자동화 범위와 승인 구조

```
주제 목록 → [AI 초안 생성] → queue/pending
      → [텔레그램 전송: ✅승인 / ❌반려 버튼] → 휴대폰에서 탭
      → approved 만 발행(블로그/인스타/뉴스레터) → 주간 리포트
```
- **자동**: 주제별 초안 작성, 큐 관리, 승인 알림, 승인분 발행, 현황 집계, 로그.
- **사람 승인 필수(자동화 금지)**: 콘텐츠 발행, 광고비 집행, 가격 변경, 환불·결제 분쟁, 고객 응대의 예외 건.
- 코드: `automation/pipeline.py` (생성→알림→수집→발행→리포트). 현재 **DRY-RUN**이며 `PUBLISH_LIVE=1`이어야 실제 발행 단계로 넘어갑니다. 채널별 발행 어댑터는 계정 연결 후 구현(TODO).
- 스케줄은 GitHub Actions 또는 Claude Code 예약 작업으로 실행 가능(계정·키 준비 후).

## 6. 리스크와 확인 필요 사항

1. **콘텐츠 정확성**: AI가 틀린 정보를 쓰면 브랜드가 무너집니다. 승인 단계에서 사실 확인을 통과해야만 발행되도록 유지하세요(초안 그대로 승인 금지).
2. **한국 규제 (확인 필요)**: 통신판매업 신고, 온라인 유료 교육 제공에 따른 평생교육·학원 관련 신고 해당 여부, 전자상거래법상 청약철회·환불 규정, 표시광고법(수익 보장·과장 광고 금지), AI 생성물 표시 의무(AI 기본법 시행 내용 확인).
3. **결제**: PG(토스페이먼츠/포트원 등) 가입에 사업자등록 필요. 사업자 없이는 선결제 검증이 막힙니다.
4. **LLM 원가 폭증**: 이용자당 일일 호출 한도 설정 필수(시뮬레이션상 원가 4,000원이면 마진 급감).
5. **자동 발행의 플랫폼 정책**: 인스타·블로그는 자동화·AI 콘텐츠 정책이 있어 계정 제한 가능. 처음엔 발행 직전까지만 자동화하고 반자동 업로드를 권장.
